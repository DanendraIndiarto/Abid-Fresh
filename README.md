# Abid Fresh – Sari Buah Belimbing Khas Tulungagung

Redesain website profil dan katalog produk untuk **UMKM Abid Fresh (Kelompok Agro Cipta Mandiri, Tulungagung)** dengan tampilan yang lebih modern, bersih, dan responsif.

## Fitur Utama
- Profil UMKM, komposisi produk, dan legalitas resmi (BPOM RI & Halal)
- Katalog produk dan daftar harga (Botol 330 ml, Paket Cup, dan Kardus)
- Kalkulator estimasi pesanan langsung terhubung ke WhatsApp
- Galeri foto interaktif (*lightbox*), video profil, serta peta Google Maps

## Teknologi
- HTML5
- CSS3
- Vanilla JavaScript

## Cara Menjalankan
Buka file `index.html` langsung di browser atau jalankan menggunakan **Live Server**.
